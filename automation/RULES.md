# Noseway generation rules — 2026-09-09

Product: adult NOSE strips only. Every generation receives the real blue pouch as
image_input[0], and the actual strip as image_input[1]. Reference URLs are pinned
to the repository commit in pipeline.py. A rework additionally receives the old
creative as image_input[2], for composition only. The old creative is never the
authority for packaging. Do not composite packaging/text with HTML, CSS or code.

Exactly ONE large, front-facing hero pouch per image. Reproduce the reference:
white NOSEWAY lettering, separate turquoise flourish, the same white line drawing
of the adult man's face, white strip, and all packaging text. Never use a kids
pouch, recolor WAY, invent a logo, alter the face, or hide the front panel.

Square 1080×1080 deliverable. Few large Bulgarian words; include an explicit list
of exact advertising text in each prompt, separate from packaging text. No
reviews, stars, testimonials, ratings, customer counts, prices or currency.
The offer must explicitly say: “Вземи 2 опаковки, третата е подарък”. Do not replace
this with a bare 2+1. Do not invent scarcity, deadlines, medical guarantees or
product facts. Diverse original concepts, one hero pouch in each.

Copy: Bulgarian, one of AIDA, PAS, 4 Ps, FAB, 4 U's, BAB, STAR, PPP, 5 C's. End with
a CTA and https://noseway.bg/produkti/lepenki-za-nos/. Offer says опаковки.

Required QA before publication: open reference and generated image, inspect logo,
face, packaging text, strip and count of pouches at full resolution. Read every
advertising word. For rework compare against the exact user feedback. Accept only
if all checks pass; otherwise give specific visual feedback and request another
attempt, maximum 3 attempts per request. Never publish an unchecked candidate.
An uncertain or exhausted request stays blocked with its existing image intact.
